# v2.0.1 — finds your data when it is one folder down

A fix for **Setup → Data Folder**. Nothing else changes.

## Pointing at a folder that holds an install

If you ran OpenStatsEngine from source out of a Google Drive folder, your data
is in the `data` folder *inside* it. Pointing Setup at the install's own folder
said *"Exists, with no OpenStatsEngine data"* — true, but no help.

**Check Folder** now looks one level down. When the data is there, it says so
and offers it as a button, with its teams and games counted:

> No OpenStatsEngine data directly in this folder, but there is some inside it:
> **Use …/OpenStatsEngine/data (12 teams, 30 games)**

Click it, then **Use This Folder**, and restart.

## When the Mac will not let it in

A Google Drive folder that macOS has not opened up to OpenStatsEngine used to
look empty. It now says it **cannot be read**, and how to fix it: allow Terminal
(which OpenStatsEngine runs inside) under **System Settings → Privacy & Security
→ Files and Folders**, or add it under **Full Disk Access**.
