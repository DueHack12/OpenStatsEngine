# v2.0.2 — the play-by-play is plays again

A fix for the play-by-play. Nothing else changes.

## No more clock lines

With the game clock coming from the Scorebot, every play was wrapped in
*"Clock stopped"*, *"Clock set to 8:26"* and *"Clock started"*. They outnumbered
the plays, and because the play-by-play keeps the latest 200 entries, a game
report's play-by-play could begin in the 3rd quarter, with the first half gone.

Clock starts, stops and sets, by hand or from the Scorebot, are now left out of:

- the **play-by-play** in the PDF report and on the Stats tab
- the console's **recent entries** list
- the **vMix plays** feed

They are still logged, so the game clock works exactly as before, and
`pbp.csv` and the **Feed Monitor** still show them.

## The report covers the whole game

The PDF report's play-by-play now runs from the first entry to the last,
however long the game.

## Feed Monitor

Its recent list showed old entries instead of the latest. It now shows the
newest twelve.
