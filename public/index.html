    Scorebot / Clock Feed

    Optional. Pulls period, clock, score, possession and down & distance from a scoreboard feed. Works with Sportzcast ScoreConnect III over MQTT — use mqtt://127.0.0.1:1883/bot/0/json when ScoreConnect runs on this machine (the topic is the URL path; try /# with Test to see everything a broker publishes). HTTP polling and WebSocket JSON feeds also work. Leave disabled to run the clock by hand.

    Paste a raw message

    Paste one raw JSON message from the Scorebot and hit Parse. It shows what OpenStatsEngine reads from it and suggests the field map — no network call needed, so you can work this out at your desk.

    Field sources

    Choose where each value comes from. Set a field to Manual and the feed will never touch it — use that for anything your scoreboard doesn't send, like the half-inning or the bases.

    vMix Data Sources
    
    
    In vMix: Settings → Data Sources → Add → XML, paste a URL below, then bind the columns to your GT title fields. The /vmix/live/ URLs always follow whichever game is active, so you set them up once for the season.
    
    
    Set the XPath as well as the URL. Each feed is a set of repeating
      <Row> elements, and vMix needs the XPath pointed at those rows — the value is
      listed beside every URL below. If you leave it at the document name you get a single row whose one
      cell reads like Timeouts Usedtimeouts_used00PREPSHS: that is a whole row's fields run
      together, and it means the XPath is selecting the document instead of the rows inside it.
    
    
    
  
    
  
    
    
    XML files on disk
    
    
    The same XML is mirrored to disk if you prefer a file-based data source. No SMB needed if vMix runs on this machine.
