# v2.0.3 — HUDL season PDFs, an import log, and no roster overwritten without asking

## HUDL season stats from the PDF

HUDL's **Season Stats & Team Leaders** report, downloaded as a PDF, now imports
directly: **Teams → Import → choose the file → Preview Stats → Import as Stats**.

It brings in all eight stat tables — passing, rushing, receiving, defense,
kicking, punting, kickoff and punt returns — plus what the saved web page never
had: the team's and its opponents' season totals (total yards, passing and
rushing lines, 3rd- and 4th-down conversions, first downs, turnovers, sacks) and
how many games the report covers.

Every value is placed by where it sits on the page, so a blank cell stays blank
instead of shifting the rest of the row a column left, and every section is
checked against HUDL's own **Total** row before anything is saved. If a number
does not add up, the import tells you which section and which stat. Other PDFs,
MaxPreps included, are still refused.

## Every stats import is logged

Importing again — next week's report, say — replaces the season's imported set,
and nothing is lost when it does:

- **Preview Stats** says what an import would replace: the earlier file and
  date, every number that changes (old → new), who is new and who has dropped
  off. It warns when the new file covers *fewer* games than the one it replaces.
- Every import is recorded in `imports.jsonl` in the data folder, with the old
  value of everything an overwrite changed. **Season History → Import log**
  lists them per team.
- The imported stats themselves now show under **Season History**, section by
  section, with the season totals.

## A roster is never overwritten without asking

- A roster import that would change a player already on the roster — position,
  jersey number, anything — or remove anyone now stops and shows exactly who
  and what, and only goes ahead when you say so. Imports that only add players
  go straight in.
- **Save Roster** asks before it writes over changes made since you opened the
  roster (an import, or another device), instead of quietly dropping them.
- Importing a roster while the editor has unsaved edits asks before discarding
  them.
- A blank cell, or a column the file does not have, no longer clears that
  field on players already on the roster.
- **Replace the roster** keeps each player the file still names as the same
  player, so plays already logged against them keep their names.

## Fixes

- A stats import blanked the position and grade of every player it matched,
  added HUDL's "D. Kane" as a second #11 beside "Dylan Kane", and added a
  nameless player for every jersey in a HUDL per-game file. It now only adds
  players the roster does not have, and never changes one that is there.
- HUDL season imports read the **DEF TD** column, add return TDs and fumbles
  from both of the tables they appear in instead of keeping only the last, and
  take games played as the most of any table.
