# v2.1.0 — OpenStatsEngine in the taskbar and the menu bar

The apps no longer open a console window. OpenStatsEngine now looks like an app
of its own, with its name and logo, on both Windows and macOS.

## Windows: a window in the taskbar

OpenStatsEngine is now its own window, titled **OpenStatsEngine**, with the
logo in the taskbar, instead of a console window carrying Windows Terminal's
name and icon. It shows the server's output as before, plus buttons to:

- **Open Stats Entry** in your browser
- **Copy Network Address** for phones and tablets
- **Restart Server**, after changing the data folder, say

Closing the window stops the server, as closing the console did. If the server
ever stops on its own, the window says so and offers **Start Server**.
Right-click the taskbar button → **Pin to taskbar** to keep it there.

**The download is now a .zip.** It holds a folder with two files:
`OpenStatsEngine.exe` (the window, the one to open) and `ose-server.exe` (the
server it runs). Right-click the zip → **Extract All** first, and keep the two
files together. A `data` folder next to them is still used, as it was next to
the old `.exe`.

## macOS: in the menu bar

OpenStatsEngine now lives in the menu bar, as the logo, instead of opening
Terminal. Its menu:

- **Open Stats Entry**, **Open Announcer View**, **Open Feed Monitor**
- **Copy** the address for phones and tablets
- **Restart Server**
- **Show Console**: the server's output, in a window titled OpenStatsEngine.
  While it is open the app is in the Dock and Cmd-Tab too.
- **Quit OpenStatsEngine**, which stops the server

The icon is dimmed while the server is not running, and if it ever stops on
its own the console opens to say why. Closing the console leaves the server
running. If the menu bar is too full to show the icon (or it is behind a
MacBook's notch), open the app again from Applications and the console comes
up.

**Google Drive on a Mac:** macOS now asks whether *OpenStatsEngine* may use a
Google Drive or other cloud folder, where it used to ask about Terminal. If you
keep your data in one, allow it when asked, or add OpenStatsEngine under
**System Settings → Privacy & Security → Files and Folders**. Setup → Data
Folder says so if it is needed.

## Also

- Options still work: add them to a Windows shortcut's **Target**, or on a Mac
  use `open -a OpenStatsEngine --args --port 9000`.
- The server never outlives its window: closing the window, quitting the app,
  or the app being ended any other way stops the server too.
- Running from source (`start-windows.bat`, `start-mac.command`,
  `node server.js`) and the Linux build are unchanged.
